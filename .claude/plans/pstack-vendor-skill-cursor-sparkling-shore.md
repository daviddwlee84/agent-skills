# pstack: evaluation → catalog-only entry

## Context

The user asked whether to vendor pstack (`cursor/plugins/pstack`, by Lauren Tan / poteto, MIT,
v0.15.28). They also asked how it works outside Cursor and whether we would need to adapt it.
**Decision (user): catalog only. Nothing goes into `vendor.yaml`.**

Evaluation findings (from upstream, 2026-10-19):

- **Size and coupling.** 56 SKILL.md files: the `poteto-mode` router with 23 playbooks, 24 `principle-*`
  leaf skills, and 2 agents (`poteto-agent`, `comment-sicko`), plus TS/Bun scripts (`orch`, `watch-pr`).
  Skills read siblings via `../<name>/SKILL.md` and an adapter at `../../docs/harness/claude-code.md`.
  Our per-skill sync (`scripts/sync-vendor.sh`) does not copy `docs/`, so vendored copies would ship broken links.
- **Churn.** Several commits a day (5 commits on 2026-10-18/19 alone). Weekly `chore/vendor-sync` PRs would be noisy.
- **Claude Code is already handled upstream.** `harness/pstack/claude-code/` is generated by
  `scripts/generate-pstack-harness-trees.mjs` and enforced by CI. Install with
  `/plugin marketplace add cursor/plugins` and then `/plugin install pstack@cursor-plugins`. Commands become
  `/pstack:<name>`. The adapter maps `Task`→`Agent`, `readonly`→`Explore`, `cloud`→`isolation: worktree`,
  and `.mdc` rules→`~/.claude/rules/pstack-models.md`. Non-Claude model slugs (the default Grok code role) fall back to the
  session model. Cursor-only features (Automations, Bugbot, cloud agents, the benny pack) are skipped with a one-line note.
  We do not need our own adaptation.
- **Codex / OpenCode / Pi / Gemini.** Upstream ships nothing official. Community ports exist, all MIT, small, and behind upstream:
  `Go7hic/ystack` (★16, last push 2026-08-09; capability-verb mapping for Claude Code/Codex/Droid/OpenCode/Cursor),
  `TheOnlyFusionCube/potetos-for-everyone` (★16, 2026-09-10; Claude Code/Pi/Codex/Gemini, built on v0.15.0+),
  `kashyab12/uni-pstack` (★0, 2026-07-10; Codex-first).
- **Picker pollution and conflicts.** Generic names (`tdd` clashes with `engineering-fundamentals/tdd`, plus `how`, `why`, `teach`,
  `recall`, `correct`, `bro`). `disable-model-invocation: true` may not be honored by every `npx skills` target.
- **Only three skills work on their own** (`unslop`, `benchmark-checklist`, `blast-radius`). They have no sibling or adapter refs.
  These are the first candidates if we revisit.
